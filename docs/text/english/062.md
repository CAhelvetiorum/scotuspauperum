{#s062-h .heading} [Twenty-fourth distinction.]

{#s062-01} On the twenty-fourth distinction it is asked whether there is, properly speaking, number in God. It seems not, because Scripture posits solitude in God; for it is said: ‘Thou alone art God.’ To the contrary: where there is a trinity, there is number; in God there is a trinity; therefore number.

{#s062-02} In this distinction there are no opinions; but for the sake of clarification four things will be considered. First, whether number is a real being or a being of reason. Second, whether it is an absolute or a relative form. Third, some conclusions will be laid down. Fourth, I shall speak to the point of the question.

{#s062-03} As to the first article, the holy Doctor says that it is a being of reason, for it does not exist when the intellect is set aside (*Physics* 4). But on this it is said, according to Scotus and his followers, that number, as regards its material being, is a real being, but as regards its formal being it is from the soul. Or otherwise: that number, taken for the number numbered, is outside the soul; taken for the numbering number, or that by which we number, it is from the soul; for according to *Physics* 4 it is the soul that numbers.

{#s062-04} [[p. 99|r° · Di.xxv. Q.i · sig. g.2]]As to the second article, it is said that it is a relative form, taking number for that from which the name is imposed; but taking number for that on which the name is imposed, that is, for the things numbered, it is an absolute form. And so either opinion can be held.

{#s062-05} As to the third, some conclusions are stated. The first: that number, as it is a relative form, is a relation that comes from within (*respectus intrinsecus adveniens*), because it is posited once the extremes are posited. The second conclusion: that it can be in a genus, and in any genus whatever; this is clear, because I may say ‘ten substances’, ‘ten quantities’, ‘ten relations’ or ‘paternities’. The third conclusion: that number can be a transcendental, because it belongs to transcendentals. The fourth conclusion: that number can be caused by the division of the continuum. The fifth conclusion: that number is in the continuum itself in potency, and through division it comes to be in act. The sixth conclusion: that number is caused not only by the division of the continuum but by distinction; for otherwise there would be no number among the angels, since angels are not continuous; yet there are nine choirs of angels, as will be seen in the second [book]. The seventh conclusion: that the foundation of number is not the same as number, nor number the same as its foundation. The eighth conclusion: that number is not constituted out of unities, since number is a positive form and unity a privative one, and the positive is not constituted by the privative; and therefore number is constituted by the one (*Metaphysics* 9), and this materially. The ninth conclusion: that number, formally, is a simple form; for six is once six. And if Aristotle says that number is a quantity aggregated out of unities, it is replied that this is a material definition.

{#s062-06} As to the fourth article, which is the answer to the question, some say that number is not posited in God; for number is a quantity, quantity is something limited, and the things posited in God are transcendentals; therefore number is not posited. But it seems to me that it is, because there is a transcendental number; for two emanations are posited there, namely generation and active spiration. Again, because Aristotle, in *De caelo* 1, says that the ternary number is perfect; wherefore it is found in God. Again, ‘there are three that bear witness in heaven, the Father, the Word and the Holy Spirit’; and so it seems that number is posited.

{#s062-07} To the argument at the beginning it is said that Scripture posits a solitude of the essence or substance, but not of the persons.
